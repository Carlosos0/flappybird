Detailed Description

Representa o menu de exclusão de jogadores.

Permite ao usuário selecionar um jogador da lista e confirmar a exclusão. Herda da classe Menu e implementa os métodos virtuais para processar eventos, desenhar o menu e gerenciar o estado do menu.
