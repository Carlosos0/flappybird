◆ Run()

void gamecontroller::Run ( )

Executa o loop principal do jogo, processando eventos, atualizando a lógica e renderizando os elementos gráficos.

O loop continua enquanto a variável "playing" for verdadeira, permitindo que o jogo seja executado até que o jogador decida sair ou o jogo seja encerrado.

◆ UpdateCountdown()

void gamecontroller::UpdateCountdown ( )
private

Atualiza a contagem regressiva, verificando se o tempo decorrido desde o início da contagem atingiu 1 segundo.

Se sim, decrementa o valor da contagem regressiva e atualiza o instante de início. Se a contagem regressiva atingir zero, muda o estado do jogo para "Playing".
